# Composer 2.5 architecture decision, round 1

Completed advisory review. Selected Vite+TanStack Router/Query; custom shadcn operator app; FastAPI modular monolith with worker, transactional outbox and PostgreSQL LISTEN/NOTIFY; query-computed visit duration; seeded fixed RBAC presets separate from physical access.

Required corrections: volunteer+ can open/receive handoff; takeover needs keyholder+ and strict higher numeric priority; >= -1 default. No external I/O in tap transaction. Dedicated minimal public projection. Highest active unexpired/unrevoked certification per type; preserve higher manual training. Email not globally unique by assumption; explicit identity conflict handling. Recheck role/device on live subscriptions. Metrics window clip, exclude forgotten/mass-forgot closures, UTC storage and New York lab dates. Device pairing and idempotent mutations.

Primary qualification: generated stored duration would not itself prevent correct reporting; it is unnecessary initially and cannot replace window-clipped duration calculation. Decision is simplicity until profiling, not claiming stored durations are inherently incorrect.

This is architecture advice only; implementation not yet reviewed. Full reviewer response is in parent task history.
